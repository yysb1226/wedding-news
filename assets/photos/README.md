# 사진 파일을 이 폴더에 넣으세요

다음 **네 장의 실제 사진**을 여기에 추가하면 페이지의 자리 표시자가 자동으로 대체됩니다.

- `couple-01.webp` — 표지
- `couple-02.webp` — 첫 번째 이야기
- `couple-03.webp` — 두 번째 이야기
- `couple-04.webp` — 마지막 인사

권장: 4:5 세로 비율, 1080×1350px, 각 200–400KB 내외. JPG 또는 PNG를 사용해도 되지만, `index.html`의 `src` 확장자를 실제 파일에 맞춰 변경해야 합니다. **파일 이름의 대소문자도 정확히 일치해야 합니다.**

사진을 공개 저장소에 올리기 **전에** GPS 등 EXIF 위치 메타데이터를 삭제하고, 사진에 주소·차량번호 등 민감한 내용이 담기지 않았는지 확인하세요. Git에 올린 뒤 삭제하더라도 이력이 남을 수 있습니다.
